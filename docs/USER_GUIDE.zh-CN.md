# TradePilot AI 界面使用指南

本文介绍当前演示版的询盘工作台和产品库。界面截图用于说明布局；模型、语言、产品和账号等显示内容会随部署配置及数据库数据而变化。

## 访问项目

Docker Compose 启动后，默认从 `http://localhost:8080` 打开前端；本地开发时通常使用 `http://localhost:5173`。后端默认地址为 `http://localhost:8000`。默认模型提供方是规则引擎；使用 Ollama 或在线模型前，需先按[部署文档](../DEPLOYMENT.md)配置后端。

## 询盘工作台

![询盘工作台：填写客户询盘、选择模型和界面语言，并查看解析结果、产品匹配及报价草稿](screenshots/inquiry-workspace.png)

工作流程如下：

1. 在“Customer inquiry”文本框中粘贴客户询盘；可选填客户公司名称。
2. 右上角可切换当前已配置的模型提供方和界面语言。
3. 点击“Run analysis”后，系统解析数量、目的地、项目类型和产品信号，并展示候选产品。
4. 浏览“Product matches”，可搜索或查看候选产品详情。
5. 选择合适产品后，报价草稿区域才会生成对应报价；仅运行解析不会自动创建报价。

截图中的 Ollama / Qwen 选项仅在后端已配置且 Ollama 服务可访问时可用。若选择模型后分析失败，可先检查后端提供方配置、模型名称及服务连通性；未配置在线服务时可使用规则引擎。

## 产品库

![产品库：搜索产品、查看产品卡片、刷新列表或显示停用产品](screenshots/products-page.png)

- 使用搜索框按产品名称或 SKU 查找商品。
- 点击“Refresh”重新加载产品列表。
- 点击“+ New product”创建产品。
- 勾选“Show inactive products”可查看已停用产品；停用产品不会从数据库删除。
- 点击产品卡片可在该产品附近展开详情；具备相应权限的用户可编辑产品信息和库存。

产品价格、SKU、库存及是否启用状态来自当前数据库。新部署时系统会初始化演示产品和库存数据；实际使用前请替换或补充为自己的目录信息。

## 报价、审批与库存

询盘分析后先选定产品，再生成报价草稿。草稿经有权限的用户审批后才会扣减预留库存；取消草稿会释放预留库存。报价、库存流水及调整记录会保存在配置的数据库中。角色权限和认证配置详见[部署文档](../DEPLOYMENT.md)。

## 界面语言与模型配置

界面提供中文、English 和 Italiano 三种语言。模型下拉框展示当前后端启用的提供方；本地模型需要运行 Ollama 并配置模型名，DeepSeek、Kimi 等在线提供方需在后端环境中设置 API Key。不要把 API Key 写入前端配置或提交到 Git。
